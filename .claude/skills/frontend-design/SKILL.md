This skill is specialized for building **high-end frontend interfaces using Nuxt (Vue 3) and TailwindCSS**, with a strong emphasis on **distinctive design, motion, and production-ready structure**.

The goal is NOT just to make things "look good", but to create **memorable, opinionated interfaces** that feel intentionally designed — not AI-generated.

---

## 🧠 Design Thinking (MANDATORY)

Before writing code, define:

### 1. Purpose
- What is being built? (landing page, SaaS dashboard, portfolio, etc.)
- Who is the user?

### 2. Aesthetic Direction (CHOOSE ONE STRONG STYLE)
Pick a clear visual identity:
- brutalist / raw
- editorial / magazine
- luxury / high-end
- futuristic / sci-fi UI
- playful / toy-like
- minimal / zen
- industrial / terminal-inspired
- neo-glassmorphism (if used, must feel fresh)
  
👉 DO NOT MIX RANDOMLY. Commit to one direction.

### 3. Differentiation
Define the **signature element**:
- unexpected layout?
- bold typography?
- immersive animation?
- strong color system?

---

## ⚙️ Technical Constraints (Nuxt + Tailwind)

- Use **Nuxt 3 composition API**
- Use **TailwindCSS (utility-first)**
- Avoid inline styles unless necessary
- Use `script setup`
- Componentize when relevant
- Keep code clean and production-ready

---

## 🎨 Design System Rules

### Typography
- Avoid: Inter, Arial, Roboto
- Use expressive fonts (Google Fonts or custom)
- Combine:
  - 1 display font (headings)
  - 1 clean body font

Example:
```css
font-family: 'Clash Display', 'General Sans', sans-serif;
